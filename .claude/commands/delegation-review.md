Prüfe eine Delegation auf Qualität und Vollständigkeit bevor sie ausgeführt wird.

Führe folgende Prüfungen durch:

**Contract-Qualität**
- [ ] Hat die Delegation ein klares, einzelnes Ziel (nicht mehrere Aufgaben in einer)?
- [ ] Sind mindestens 3 konkrete Definition-of-Done Items vorhanden?
- [ ] Ist der Risk Class korrekt (A=neue Dateien, B=bestehende Dateien ändern, C=Schema/Auth/Security)?
- [ ] Ist das Budget realistisch für den Scope? ($2=80 Turns, $3=120 Turns, $5=200 Turns)
- [ ] Sind keine PII oder Secrets im Context?

**Scope-Check**
- [ ] Ist der Scope auf 1-3 Dateibereiche begrenzt?
- [ ] Gibt es klare Grenzen was NICHT gemacht werden soll?

**Empfehlung**: READY TO RUN / NEEDS REFINEMENT / SPLIT INTO TWO

Zeige konkrete Verbesserungsvorschläge wenn NEEDS REFINEMENT.
