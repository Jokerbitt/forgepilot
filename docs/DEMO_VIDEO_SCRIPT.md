# ForgePilot Demo Video Script

Target length: 3-4 minutes.

## 0:00 — Problem

"AI coding tools are powerful, but the workflow around them is still messy. Ideas live in chats, tasks overlap, agents touch the same files, reviews are inconsistent, and project context disappears."

Show:

- Command Center
- Delegations
- Agent Control Plane

## 0:25 — What ForgePilot Is

"ForgePilot is a local-first AI workflow OS. It turns ideas into project briefs, work packages, agent delegations and pull requests, while keeping humans in control."

Show:

- `/`
- `/projects`
- `/project-briefs`

## 0:50 — Idea To Brief

Steps:

1. Open Project Briefs.
2. Create or select an idea.
3. Show requirements, risks and next work packages.

Narration:

"Instead of asking an AI to code immediately, ForgePilot first structures the problem."

## 1:25 — Delegation

Steps:

1. Open a work item or brief.
2. Create a delegation.
3. Show acceptance criteria, file scope and risk.

Narration:

"Each agent receives a contract: what to build, what not to touch, how to verify it, and when to escalate."

## 1:55 — Agent Coordination

Steps:

1. Open Agent Control.
2. Show active write scopes.
3. Explain scope claims and conflict prevention.

Narration:

"This is where ForgePilot becomes more than a task tracker. It coordinates agents so they do not step on each other."

## 2:25 — Local-First Routing

Steps:

1. Open Model Router.
2. Show local providers and cloud providers.
3. Explain local-first strategy.

Narration:

"Small tasks can run locally through Ollama or LM Studio. Expensive cloud models are reserved for complex or high-risk work."

## 2:55 — Readiness And Trust

Steps:

1. Open SaaS Readiness.
2. Show Auth, Tenant, Billing, Privacy and Pricing checks.
3. Open Cost Analytics or Provider Health.

Narration:

"ForgePilot is honest about readiness. It shows what is ready, what is partial, and what blocks a real SaaS launch."

## 3:25 — Close

"The goal is not blind autonomy. The goal is reliable AI-assisted delivery: scoped work, visible agents, local-first efficiency, human approval, and durable project memory."

End screen:

- GitHub repo
- local-first
- self-hosted
- AI workflow OS
